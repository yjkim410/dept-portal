# 재무 계산기 & 용어 사전 (부서 포털)

단일 HTML 파일(`index.html`)로 동작하는 부서 내부용 정적 포털임. 서버·설치 없이 브라우저에서 바로 열어 사용함.

## 폴더 구성

| 경로 | 설명 |
|---|---|
| `index.html` | 포털 본체 (CSS·JS 포함 단일 파일) |
| `files/` | PDF·Word 등 배포용 자료 보관 폴더 (파일명은 영문 소문자·하이픈 권장) |
| `files/daily-finance-tax-basic-guide.pdf` | 생활 재무·세금 기초 가이드 |
| `files/finance-glossary.pdf` | 재무 용어집 |
| `이전버전/` | 개편 전 원본 보관 (`dept-portal-v2.html`) |
| `README.md` | 본 안내서 |

## 실행 방법

1. `index.html`을 더블클릭하여 브라우저(Chrome·Edge 권장)에서 열기
2. 사내 웹서버·공유 드라이브에 게시할 경우 `index.html`과 `files/` 폴더를 같은 위치에 함께 복사

## 메뉴별 사용법

상단 메뉴(홈·계산기·용어 사전·FAQ·자료실)로 구간 이동함.

### 1. 계산기
- **부가세 계산기**: `공급가액 입력` 또는 `합계금액 입력` 선택 → 금액·세율(기본 10%)·원 미만 처리 방식 입력 → 공급가액·부가세·합계금액 확인
- **대출 이자 계산기**: 원금·연 이자율·기간(년/개월)·상환 방식 입력 → 월 납입액, 총 이자, 총 상환액, 원금 대비 이자 비율 및 상환 스케줄표 확인
- **환율 환산기**: 통화 코드·환율 기준 단위·환율을 직접 입력 → 방향(외화→원화 / 원화→외화), 금액, 환전 수수료율(선택) 입력 → 수수료 반영 후 금액 확인
  - 환율은 자동 조회가 아닌 **직접 입력** 방식임. 기준 환율은 한국은행 ECOS 등에서 확인 필요

### 2. 용어 사전
- 검색창에 용어 입력(예: 원천징수, DSR, 환율) 시 실시간 필터링 및 검색어 강조 표시
- 분류 칩으로 카테고리별 필터링, 검색 결과 건수 표시

### 3. FAQ
- 자주 묻는 재무 질문 목록 (질문 클릭 시 펼침/접힘)

### 4. 자료실
- 외부 공식 사이트 바로가기 6종: 홈택스, 국세청, 국가법령정보센터, 금융감독원 '파인', 금융위원회, 한국은행 ECOS
- 링크는 모두 외부 URL이며, 새 자료(PDF·Word) 추가 시 `files/`에 저장 후 `index.html` 자료실 구간에 카드를 추가함

## 유지보수 안내

- 자료 파일명 규칙: 한글·공백 없이 영문 소문자와 하이픈 (예: `vat-guide-2026.pdf`)
- `files/` 내 파일을 연결할 때 상대경로 사용 (예: `href="files/vat-guide-2026.pdf"`)
- 수정 전 `이전버전/`에 사본 보관 권장
- 계산 결과는 참고용이며, 신고·회계처리 등 실무 적용 전 법령·기준 원문 대조 필요함
